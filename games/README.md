# Games Library

**Core rule:** The neuro-stimulus is built *into* real Taekwondo movement — not added alongside it. Technique is never compromised for the neuro-element. If a non-TKD movement is required, it is flagged explicitly.

## How to Use This Library

Each game is a complete, stand-alone file containing:
- **Neuro-Target:** the nervous system capacity being trained
- **Taekwondo Technique:** the TKD movements, with form-preservation notes
- **TKD Link:** how the game transfers to sparring, Poomsae, or technique
- **Setup & How to Play:** step-by-step instructions
- **Variations:** easier and harder progressions
- **Log Metric:** what to measure and track
- **Why It Works Neurologically:** the science behind the stimulus

### For Session Planning
- See [`sessions/`](../sessions/) for two template session plans
- Pick 6–8 games total for any session (warm-up → main → cool-down order)

### For Assessment
- See [`assessment/`](../assessment/) for tracking metrics and retest rhythm
- **Primary metric:** C1 Balance Hold (seconds) — retest every 4–6 weeks
- **Secondary metrics:** reaction speed, Poomsae stability, landing quality

### Non-TKD Flags
Games that include non-TKD movements are clearly marked with ⚠ and justified:
- **M2 Vestibular Dollyo:** rotation is non-TKD (justified: no TKD move creates same vestibular perturbation)
- **M6 Vestibularer Gangpfad:** walking circuit is non-TKD (justified: multi-directional vestibular + gaze stimulus for sparring footwork)
- **C2 Atem-Augen-Fokus:** breathing protocol is non-TKD (justified: specific parasympathetic trigger for cool-down)
