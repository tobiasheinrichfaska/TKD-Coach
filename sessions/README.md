# Sessions

Concrete sessions — a [session template](../session-templates/) instantiated for a specific **group + date** (the thing you actually run). IDs `S-YYYY-MM-DD-<group>`. Frontmatter: `date`, `group`, `template`, `coaches`. See [STRUCTURE.md](../STRUCTURE.md).

A session file is the **plan/record + notes**. Live run data (per-game durations, attendance) is captured by the app at runtime; notable or example sessions can be committed here as markdown.
