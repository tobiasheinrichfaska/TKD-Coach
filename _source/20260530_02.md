# NEURO-TKD LOG v1 · 2026-05-30
## Context
Coach · Breitensport · mixed age (kids 8–13, youth, adults) · Germany · 2h kids / 1.5h youth-adult sessions

## Core Principle
Neuro-stimulus embedded IN real TKD technique. Never compromise form. If non-TKD movement required, state why explicitly.

## Games Library (10 confirmed, phase-tagged)

### WARM-UP
**W1 · Farben-Chagi**
Neuro: visual-motor coupling, cue→motor selection
Tech: Ap/Dollyo/Yop Chagi (full form, only trigger is neural)
Setup: 3–4 colored cones/paper
Play: Color = kick. Coach signals → execute. No anticipation.
Var↓: 2 colors, slow. Var↑: opposite-color rule, combo (2 colors = sequence)
Kids: love color naming · Adults: faster cadence, opposite-color
Log: reaction errors per 10 cues
Time: 6–8min

**W2 · Spiegel-Stand**
Neuro: visual-proprioceptive mirroring, anticipation suppression
Tech: Stances (Ap Seogi, Juchum), step-switches, Makki blocks
Play: pairs, leader changes stance/block, partner mirrors immediately. Form policed.
Var↑: add direction changes, freeze cue
Time: 5min

**W3 · Koordinationsleiter → Stance-Exit**
Neuro: proprioceptive sequencing, motor-program chaining
Tech: ladder footwork → exit into named stance (held 2s)
Var↑: faster patterns (in-in-out, crossover), deeper stances · Adults: crossover exit
Time: 8min

### MAIN
**M1 · Zahlen-Kombi**
Neuro: working memory + visual cue → sequenced motor output
Tech: numbered kick/strike combos on pads, full technique
Setup: pads, optional number cards
Play: 1=jab, 2=Dollyo, 3=back kick… coach calls sequence → execute
Var↑: longer sequences, reverse order, distraction noise
Log: correct sequence completions / attempts
Time: 10–12min

**M2 · Vestibular Dollyo**
Neuro: vestibular recalibration post-rotation → stable chamber & kick
Tech: 1–2 controlled spins → full Dollyo Chagi, clean landing
Note: spin is deliberate non-TKD vestibular stimulus (justified for spinning-kick transfer); kick stays authentic
Spotting emphasized. Shields at stations.
Var↑: 2 rotations, eyes-closed spin segment
Log: landing stability (stable/stumble/fall per set)
Time: 12min

**M3 · Einbein-Poomsae**
Neuro: proprioceptive + vestibular, single-leg postural control under cognitive load
Tech: Poomsae arm segments on one leg; full Poomsae attempt on one leg (simplified sequence)
Var↑: eyes closed · Var on mat for safety
Log: hold time before foot touches / sequence errors
Time: 12min

**M4 · Poomsae unter Störung (Perturbation)**
Neuro: motor-program persistence under visual/social distraction
Tech: full Poomsae, uncompromised
Play: partner creates peripheral visual distraction (hand movements) while performer runs sequence
Transfer: grading pressure, sparring distractors
Log: sequence errors vs. baseline
Time: 18min

**M5 · Reaktions-Zahl-Kreis**
Neuro: auditory cue → block selection, attentional focus, group re-engagement
Tech: Makki blocks (Arae, Momtong, Olgul) called by number/color
Play: circle, coach calls number → correct block. Wrong block = small penalty (5 pushups or sit out 1 round)
Log: error count per round
Time: 8min (re-engagement tool)

### COOL-DOWN / ASSESSMENT
**C1 · Balance-Hold Test**
Neuro: proprioceptive baseline measurement
Tech: single-leg Poomsae stance (chamber position), timed
Frame as game/competition not test
Log: seconds before foot down → PRIMARY TRACKING METRIC
Retest: every 4–6 weeks

**C2 · Atem-Augen-Fokus**
Neuro: parasympathetic activation, gaze stabilization
Tech: low stance, wall fixation point, 4-in/6-out breathing
Kids: 6–8 breaths · Adults: 10–12 breaths
Non-TKD movement (breathing protocol) — justified: no TKD technique serves this cool-down parasympathetic function
Time: 8–12min

## Vestibular Walk Drill (separate — kids 8–13 specifically)
Protocol: fix gaze → walk back 6m → side 6m (peripheral marker) → fwd 6m → side 6m × 3 turns, then repeat with opposite lateral direction × 3
Predicted reactions (kids):
- Social: laughter, comparison, peer encouragement ~60s in
- Physical: mild stumble at turn 1, progressive improvement turns 2–3; some dizziness reports
- Psychological: initial uncertainty → growing confidence → pride
- Bodily: elevated HR, slight nausea in sensitive kids, improved gaze stability by turn 6
Adults: mask difficulty, need partner accountability for gaze breaks; frame as elite protocol not balance game
Adults dosage: can sustain 8–10 cycles before vestibular fatigue (vs ~6 for kids); reduce rest between turns to increase stimulus density
Progression variant (adults): add cognitive dual-task — count backwards in 3s during walk; occupies prefrontal, forces vestibular reflex to carry full balance load
