# Neck Rotations + Refocus

*From the [Mobility / Warm-Up / Stretching protocol](../../session-templates/ST-mobility-stretching-protocol.md).*

**How:** Slow cervical rotations with gaze refocus. ⚠ mild dizziness = vestibular stimulus, build slowly.

**Dose:** gentle, a few each way

**Covers:** Cervical spine; SCM/scalenes/traps/deep neck flexors. Vision + vestibular.
