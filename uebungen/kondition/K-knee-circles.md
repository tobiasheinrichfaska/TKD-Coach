# Knee Circles

*From the [Mobility / Warm-Up / Stretching protocol](../../session-templates/ST-mobility-stretching-protocol.md).*

**How:** Hinge only — never crank. Small controlled circles.

**Dose:** 2–3 each direction — gentle, small amplitude

**Covers:** Tibiofemoral/patellofemoral joint; patellar tendon.
