# Ankle Circles

*From the [Mobility / Warm-Up / Stretching protocol](../../session-templates/ST-mobility-stretching-protocol.md).*

**How:** Slow circles at true end range; brace the foot/lower leg.

**Dose:** 2–3 each direction, both feet

**Covers:** Talocrural/subtalar joint; tib. ant., peroneals, gastroc/soleus.
