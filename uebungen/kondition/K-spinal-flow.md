# Spinal Flow

*From the [Mobility / Warm-Up / Stretching protocol](../../session-templates/ST-mobility-stretching-protocol.md).*

**How:** cat → puppy → cow → cobra → cat, then reverse. Continuous and breath-paced.

**Dose:** 1–2 continuous passes

**Covers:** Whole spine; puppy = lats/posterior shoulder/thoracic ext.; cobra = rectus abdominis, hip flexor, pec.
