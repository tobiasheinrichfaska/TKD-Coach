# Single-Leg Balance (eyes open→closed)

*From the [Mobility / Warm-Up / Stretching protocol](../../session-templates/ST-mobility-stretching-protocol.md).*

**How:** Balance on one leg; progress eyes open → closed.

**Dose:** 20–30 s / side

**Covers:** Ankle/foot proprioceptors, glute-med, core. Proprioception + vestibular.
