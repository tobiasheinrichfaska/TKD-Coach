# M1 · Zahlen-Kombi

*Working memory + kick combination sequencing*

**Main** · **10–12 min** · **All ages** · **Working Memory + Visual**

---

## Neuro-Target

Working memory → sequenced motor output. Holding a number sequence in working memory while executing full-form techniques — exactly the neural demand of a multi-kick combination in sparring.

## Taekwondo Technique

Full kick and strike techniques: 1 = jab · 2 = Dollyo Chagi · 3 = back kick · 4 = Yop Chagi · 5 = Olgul Makki. All techniques executed with full form, full chamber, correct retraction.

✓ **Full kick/strike technique — form never reduced**

## TKD Link

Combination sparring · sequence memory · pad work · reaction combinations

## Setup

Pads (1 per pair). Optional: numbered cards coach holds up. Each pair: 1 kicker + 1 pad holder.

## How to Play

1. Establish number map (write on board or verbal at start)
2. Coach calls a 2–3 number sequence: "2 – 1 – 3"
3. Kicker executes full sequence on pads, in order
4. Pad holder gives resistance on kicks, no visual cues
5. Rotate kicker/holder every 90s. Increase sequence length as session progresses.

## Variations

| ↓ Easier | ↑ Harder |
|---|---|
| 2 numbers max · visual card cue · repeat sequence aloud before executing | 4–5 numbers · reverse order · add distraction noise · no repeat allowed |

> **Log:** correct sequence completions / attempts per pair. Group race: who completes 5 clean combos first?

## Why It Works Neurologically

Prefrontal working memory must hold and order the sequence while the motor system executes each full movement. This dual-demand training directly mirrors sparring cognition: planning the next move while executing the current one. Longer sequences overload working memory capacity, forcing faster automatization of individual techniques.
