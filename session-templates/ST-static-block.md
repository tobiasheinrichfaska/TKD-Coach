# Static Stretching Block

Phase 4 of the [Mobility / Warm-Up / Stretching protocol](ST-mobility-stretching-protocol.md). **Post-session, or standalone when warm.** 30–60 s per hold; active end-range + PNF on the split directions. ⚠ Never before explosive work (blunts power) and never cold.

## Sequence

| Übung | Dose | Tracked measure |
|---|---|---|
| [D-standing-forward-fold](../uebungen/dehnung/D-standing-forward-fold.md) | 30–60 s | Forward fold |
| [D-seated-forward-fold](../uebungen/dehnung/D-seated-forward-fold.md) | 30–60 s | Sit-and-reach |
| [D-hip-flexor-lunge](../uebungen/dehnung/D-hip-flexor-lunge.md) | 30–60 s/side | Front split |
| [D-straddle-pancake](../uebungen/dehnung/D-straddle-pancake.md) | 30–60 s | Side split |
| [D-butterfly](../uebungen/dehnung/D-butterfly.md) | 30–60 s | — |
| [D-downward-dog](../uebungen/dehnung/D-downward-dog.md) | 30–60 s | — |

Close with [C3 · Atem-Fokus / Meditation](../uebungen/neuro-game/C3-atemfokus-meditation.md). Flexibility tracked monthly — see [assessment/flexibility-measures.md](../assessment/flexibility-measures.md).
