# Warm-Up — Mobility Floor + Dynamic

Phases 1+2 of the [Mobility / Warm-Up / Stretching protocol](ST-mobility-stretching-protocol.md). Run **before** training. Open with ~4–6 rounds of triangle breathing (arrive, focus).

## Sequence

| Block | Übung | Dose |
|---|---|---|
| Mobility floor | [K-ankle-circles](../uebungen/kondition/K-ankle-circles.md) | 2–3 ea. dir |
| Mobility floor | [K-knee-circles](../uebungen/kondition/K-knee-circles.md) | 2–3 ea. |
| Mobility floor | [K-hip-cars](../uebungen/kondition/K-hip-cars.md) | 2–3 ea. |
| Mobility floor | [K-scorpion](../uebungen/kondition/K-scorpion.md) | 5–6/side |
| Mobility floor | [K-spinal-flow](../uebungen/kondition/K-spinal-flow.md) | 1–2 passes |
| Dynamic | [K-leg-swings-fb](../uebungen/kondition/K-leg-swings-fb.md) | 10/leg |
| Dynamic | [K-leg-swings-lat](../uebungen/kondition/K-leg-swings-lat.md) | 10/leg |
| Dynamic | [K-march-knee-heel](../uebungen/kondition/K-march-knee-heel.md) | ~10 m |
| Dynamic | [K-footwork-skip](../uebungen/kondition/K-footwork-skip.md) | 30–60 s |
| Dynamic | [K-neck-refocus](../uebungen/kondition/K-neck-refocus.md) | gentle |
| Dynamic | [K-single-leg-balance](../uebungen/kondition/K-single-leg-balance.md) | 20–30 s/side |

⚠ Never stretch statically before explosive work — static holds go in [ST-static-block](ST-static-block.md), post-session.
